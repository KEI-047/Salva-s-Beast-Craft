# OANDA 読み取り専用プロキシ

OANDA証券のAPIトークンを**ブラウザに一切渡さず**、為替レートだけを取得するための Cloudflare Workers プロキシです。

## なぜプロキシが必要か

OANDAのAPIトークンは**発注権限を持ちます**。一方このアプリは静的ページとして配信されるため、JavaScriptに書いた値は誰でも読めます（実際、現在のTwelve DataのAPIキーは配信JSから読み取れます）。

トークンを直接埋め込むと**第三者があなたの口座で取引できてしまう**ため、トークンはサーバー側にのみ置きます。

## 勝手にトレードされないための多層防御

| 層 | 対策 | 効果 |
|---|---|---|
| 1 | **クライアントからパスを受け取らない** | 上流URLはWorker内で組み立てる。発注APIに到達しようがない |
| 2 | **上流へは GET 固定** | OANDAの発注は POST/PUT。HTTPメソッド上も不可能 |
| 3 | **通貨ペアは許可リスト方式** | リストにない文字列は上流に一切渡らない |
| 4 | **トークンは Secret 管理** | ブラウザにもGitにも保存されない |

### 本番口座のトークンを使う場合のリスク認識

本設定は本番口座(`OANDA_ENV = "live"`)を前提にしています。前提として押さえておくべき点は次のとおりです。

- **APIから出金はできません。** 出金・資金移動はOANDA Hubの画面操作が必要で、v20 APIのエンドポイントは取引系(注文・建玉・口座情報)に限られます。したがってトークンが漏れても**攻撃者が金銭を持ち出す経路はありません**。
- ただし**悪意ある建玉で残高を毀損される余地は残ります**。金銭的な利得が無いため愉快犯に限られますが、ゼロではありません。
- **上記の多層防御はプロキシを通る通信のみを守ります。** 生のトークンを入手した相手はプロキシを迂回してOANDAを直接呼べるため、最後の砦は「トークンを漏らさないこと」です。

そのため、以下は必ず実施してください。

1. トークンとアカウントIDは **Secret としてのみ** 登録する(`wrangler.toml` には絶対に書かない。公開リポジトリにコミットされます)
2. **Cloudflareアカウントに2要素認証を設定する**(Secretはダッシュボードから閲覧できませんが、アカウントを奪われるとWorkerのコードを書き換えて盗まれます)
3. デプロイ後、**発注不可を自分の目で確認する**(後述の「動作確認」)

> リスクを完全に避けたい場合は、デモ口座(fxTrade Practice)のトークンを使う手もあります。練習環境は本番環境のコピーで**市場データは本物・資金は偽物**のため、漏洩しても失うものがありません。その場合は `OANDA_ENV` を `practice` に変えてください。ただしデモ口座は**30日で期限切れ**(ゴールドステータスなら継続設定可)で、本番口座とは別のメールアドレスが必要です。

### 検証済みの攻撃パターン

以下はすべて上流に1回も到達せずWorker内で拒否されることをテスト済みです。

- パストラバーサル（`../../accounts/123/orders`）
- スラッシュ直書き / URLエンコード済みスラッシュ
- 許可ペアへの混入（`USD_JPY,../../orders`）
- クエリ注入
- `/orders` パスを直接叩く
- POST / PUT / DELETE / PATCH

## セットアップ手順

### 0. 前提条件を確認する（重要）

OANDA証券のREST APIは誰でも使えるわけではありません。**次の3つをすべて満たす必要があります。**

| 条件 | 内容 |
|---|---|
| 会員ステータス | **ゴールド会員以上**（維持には月間取引量 $500,000 が必要） |
| 口座残高 | **NYサーバーの残高が25万円以上** |
| 取引コース | **プロコース**（ベーシックコースでは不可） |

デモ口座だけでの発行はできません。**本番口座が上記条件を満たしている場合にのみ**、デモ口座でもAPIが使えるようになります。

#### プロコースへの変更にはコストが伴います

コース変更はマイページからいつでも可能ですが、**スプレッドが広がります**。

| コース | USD/JPY スプレッド | API |
|---|---|---|
| NY ベーシックコース | 0.4銭 | ✗ |
| NY プロコース | **0.8銭** | ✓ |

スプレッドが倍になるため、取引コストが上がります（損切り10pips・RR1:1.5の場合、損益分岐勝率が 41.6% → 43.2% に上昇）。資金30万円・1日2トレードなら月あたり約5,000円の追加コストです。

**データ表示のためだけにプロコースへ変更するかは、慎重に判断してください。** 本アプリは Twelve Data 構成でも15分足のシグナル・統計・自動更新がすべて動作します。OANDAで追加されるのは主に「現在値の常時表示」と「形成中の足」です。

### 1. OANDA証券でトークンを発行する

1. [OANDA証券](https://www.oanda.jp/) の本番口座にログイン
2. 「口座管理」→「**APIアクセスの管理**」
3. ライセンスに同意して「**REST APIトークンを発行する**」
4. トークンを控える（**この値は誰にも見せない・Gitに入れない・チャットに貼らない**）

> 条件を満たしていない場合、この画面に「プロコースでないためご利用頂けません。」等のエラーが表示されます。

### 2. アカウントIDを控える

現在値の取得(`/pricing`)にはアカウントIDが必要です。OANDAの口座画面（「口座管理」または「FXサブアカウント管理」）で確認できます。`101-009-1234567-001` のような形式です。

> `wrangler.toml` には書かないでください。このファイルは公開リポジトリにコミットされます。次の手順で Secret として登録します。

### 3. Cloudflare Workers にデプロイする

```bash
cd oanda-proxy

# Cloudflareにログイン（無料アカウントでOK）
npx wrangler login

# トークンとアカウントIDをSecretとして登録
# （対話式で入力。ファイルにもGitにも残りません）
npx wrangler secret put OANDA_TOKEN
npx wrangler secret put OANDA_ACCOUNT_ID

# デプロイ
npx wrangler deploy
```

デプロイ後に表示される URL（例: `https://hayabusa-fx-oanda-proxy.<あなた>.workers.dev`）を控えます。

### 4. 動作確認

```bash
curl "https://<あなたのURL>/candles?instruments=USD_JPY&count=3"
```

`{"USD_JPY":{"status":"ok","candles":[...]}}` が返れば成功です。

現在値も確認します。

```bash
curl "https://<あなたのURL>/pricing?instruments=USD_JPY"
```

`{"USD_JPY":{"bid":"...","ask":"...","mid":"...","tradeable":true}}` が返れば成功です。

発注できないことも確認できます（どちらもエラーになります）:

```bash
curl -X POST "https://<あなたのURL>/candles?instruments=USD_JPY"   # -> 405
curl "https://<あなたのURL>/v3/accounts/123/orders"                # -> 404
```

### 5. アプリ側をOANDAに切り替える

プロジェクトルートの `.env` に追記します。

```bash
EXPO_PUBLIC_OANDA_PROXY_URL=https://<あなたのURL>
```

この環境変数が設定されていれば自動的にOANDA経由になり、未設定なら従来どおり Twelve Data を使います。ビルドし直せば切り替わります。

```bash
npx expo export --platform web
```

### 6. 呼び出し元を限定する（推奨）

`wrangler.toml` の `ALLOWED_ORIGIN` を自分の公開URLに設定しておくと、他サイトからの呼び出しを弾けます。

```toml
ALLOWED_ORIGIN = "https://kei-047.github.io"
```

変更後は `npx wrangler deploy` で再デプロイしてください。

## OANDAに移行すると何が変わるか

| | Twelve Data（無料） | OANDA（本番口座） |
|---|---|---|
| レート制限 | 8回/分・800回/日 | 120回/秒 |
| 23ペアの取得 | 6ペアずつ約4分 | **一度に取得** |
| 自動更新 | 1日31回まで | **無制限** |
| レートの一致 | 取引所と別ソース | **実際に取引する値と一致** |
| 現在値の表示 | 不可 | **5秒ごとに更新** |
| 形成中の足 | 不可 | **チャートに反映** |
| 分割取得・クレジット管理 | 必要 | 不要（自動で無効化されます） |
| 料金 | 無料 | 無料（口座があればOK） |

## 注意点

- OANDAのAPI利用規約では、APIは同社との取引を目的としたものとされています。データ取得のみの長期利用は規約変更の対象になる可能性があります。
- **このアプリに自動売買を追加する場合は設計の見直しが必要です。** 現在は「シグナルを見て手動で発注する」前提のため、アプリ側の不具合が実弾の誤発注につながる経路がありません。自動売買を足すとその前提が崩れます。
