# 旅程タイムゾーンカレンダー

海外旅行時の複雑な時差と日付変更を自動で計算し、現地時間と基準時間（日本時間など）の両方でスケジュールを表示する旅行日程管理アプリです。ビルド不要の静的サイトとして動作します。

## 解決したい課題

旅行中、出発地と目的地の時差や日付変更により「現地時間ではいつなのか」「今どの時間帯にいるのか」が直感的に把握しづらいという課題を解決します。

## 主な機能

- **現地時間ベースの入力**: 目的地（現地）の時間軸でそのまま予定を入力できます。入力した予定は自動的に現地時間と基準時間（デフォルトは日本時間）の両方でカレンダーに表示されます。
- **時差自動計算・日付ズレの表示**: フライトの出発・到着時刻や現地の活動時間から、時差による日付のズレ（+1日 / -1日）を自動計算し、正確な時系列で表示します。
- **直感的なUI**: Googleカレンダーのような見やすいタイムライン形式のUI。
- **タイムゾーン切り替え**: 基準タイムゾーンの変更、カレンダーの並び基準（現地日付 / 基準日付）の切り替えが可能です。
- **アラート通知**: 予定の開始が近づくと画面上にバナー表示し、ブラウザ通知の許可があればデスクトップ通知も送信します。

## 技術スタック

- Vanilla HTML / CSS / JavaScript（外部ライブラリ・ビルド不要）
- タイムゾーン変換は `Intl.DateTimeFormat` / `Intl.supportedValuesOf("timeZone")` などブラウザ標準の Intl API のみで実装（IANA タイムゾーンデータベースに基づく正確な変換）
- データはブラウザの `localStorage` に保存（サーバー不要）

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドや依存関係のインストールは不要です。

1. 「＋ 予定を追加」から、アクティビティまたはフライトを登録します。
2. アクティビティは現地タイムゾーンと開始（任意で終了）日時を、フライトは出発地・到着地それぞれのタイムゾーンと日時を入力します。
3. 登録した予定は現地時間・基準時間の両方でタイムラインに表示され、日付がずれる場合はバッジで示されます。
4. 「🔔 通知を有効にする」を押すと、予定開始が近づいた際にブラウザ通知を受け取れます。

## 構成

- `index.html` - ページ構造
- `style.css` - スタイル（Googleカレンダー風のUI）
- `script.js` - タイムゾーン変換ロジック、状態管理、レンダリング
