# Salva's Beast Craft

ボタンを押すとランダムなビースト（モンスター）が生成されるシンプルな静的サイトです。
GitHubでコードを公開・共有する練習用に作成しました。

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドや依存関係は不要です。

## 構成

- `index.html` - ページ構造
- `style.css` - スタイル
- `script.js` - ビースト生成ロジック
- `lottery/` - ロト6・ロト7 予測（クイックピック）アプリ

## ロト6・ロト7 予測アプリ

`lottery/index.html` をブラウザで開くと使えます。ロト6（1〜43から6個）・
ロト7（1〜37から7個+ボーナス2個）のルールに沿って数字をランダム生成する
クイックピックツールです。抽選結果は完全にランダムなため、当選を予測・
保証するものではありません。
