# Hayabusa FX (15分足版)

15分足のテクニカル指標にもとづいて為替の売買シグナル(買い / 売り / 様子見)を表示する、Expo (React Native) 製のモバイル/Webアプリです。

## 主な機能

- 松井証券FXの取扱ラインナップを参考にした通貨ペア(対円14ペア + クロス9ペア、計23ペア)を「対円」「クロス」でグループ表示するウォッチリスト
- **エントリー時刻カウントダウン**: 15分足が確定する 00 / 15 / 30 / 45 分までの残り時間を秒単位で表示。残り1分を切ると色が変わり、エントリー準備の合図になります
- **統計にもとづく予測**(詳細画面):
  - **次の15分の想定レンジ**: 直近の15分足リターンの標準偏差から、約68%(±1σ)/約95%(±2σ)で収まる価格帯を算出
  - **現在シグナルの過去成績**: 表示期間内で同じシグナルが出た全ての足について、次の15分足がシグナル方向へ動いたかを集計した勝率・的中数・平均変動率。50%を境に色分けし、サンプルが少ない場合は警告を表示
  - 買い/売り両シグナルの勝率とサンプル数の比較
- 各ペアの詳細画面で、15分足の価格チャート(1日 / 3日 / 5日分)とシグナル根拠を表示
- SMA(短期5本・長期20本)のクロス、RSI(14)の買われ過ぎ・売られ過ぎ、MACDヒストグラムを組み合わせたルールベースの売買シグナル
- Pull to refresh でウォッチリストを再取得
- Expo Web出力に対応し、スマホのブラウザからインストール不要で開けるモバイルWeb版あり

### 統計値の算出方法について

勝率は、画面表示中のシグナルと**まったく同じ判定ロジック**(`src/utils/signal.ts` の `scoreAt`)を過去の各足に適用して集計しています。表示と検証でロジックが食い違わないよう、両者は同じ関数を共有しています。

ただしこれは表示期間の過去データを集計した**過去成績**であり、将来の成績を保証するものではありません。想定レンジも価格がランダムに動くと仮定した統計的な目安で、方向性を予測するものではありません。

※ 取扱通貨ペアは公開情報をもとにした一覧です。最新の正確な取扱状況は[松井証券FX公式サイト](https://www.matsui.co.jp/fx/)でご確認ください。本アプリは松井証券の口座・取引システムとは連携していない、独立したシグナル参考ツールです。

## データソース

[Twelve Data](https://twelvedata.com/)の為替15分足API(`/time_series`)を使用しています。

無料プランの上限は **8クレジット/分・800クレジット/日** です。バッチリクエストは「シンボル数 = 消費クレジット数」となるため、23ペアを一度に投げると即座に429(レート制限)になります。これを踏まえて次の対策を入れています。

- **分割取得**: 6ペアずつ・約65秒間隔で順に取得し、届いたぶんから画面に表示(最初の6ペアはすぐ表示されます)
- **キャッシュの永続化**: 取得結果は10分間 `localStorage` に保存するため、**ページを再読み込みしてもAPIを叩き直しません**。これがないと、リロードのたびにクレジットを消費して429を誘発します
- **429からの自動復帰**: レート制限に当たっても待機して自動で再試行します(最大3回)。画面には待機中である旨を表示し、エラーにはしません

1回の全体更新で23クレジット消費するので、1日あたり約34回まで全体更新できます。

## セットアップ

1. [Twelve Data](https://twelvedata.com/pricing)で無料アカウント(Basicプラン)を作成し、APIキーを取得します。
2. プロジェクトルートに `.env` ファイルを作成し、取得したキーを設定します(`.env.example` を参照)。

   ```bash
   cp .env.example .env
   # .env を編集して EXPO_PUBLIC_TWELVEDATA_API_KEY にキーを設定
   ```

3. 依存関係をインストールし、起動します。

   ```bash
   npm install
   npx expo start
   ```

Expo Go アプリ(iOS / Android)で表示された QR コードを読み取るか、iOS シミュレータ / Android エミュレータで起動してください。

## モバイルブラウザ版(Web版)

インストール不要で、スマホの Safari / Chrome から直接使えるWeb版も用意しています。

```bash
npx expo start --web
```

表示されたURLをスマホのブラウザで開いてください。スマホ幅に最適化されたレイアウトで、PCなど広い画面で開いた場合も中央にスマホ相当の幅で表示されます。

配信用に静的ファイルを書き出す場合は以下を実行し、`dist/` を任意のホスティングサービスにアップロードしてください(`EXPO_PUBLIC_TWELVEDATA_API_KEY` はビルド時にJSバンドルへ埋め込まれるため、公開ページのソースからは誰でも読める状態になります。無料枠キーであることを踏まえたうえでご利用ください)。

```bash
npx expo export --platform web
```
