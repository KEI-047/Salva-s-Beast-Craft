# Hayabusa FX (15分足版)

15分足のテクニカル指標にもとづいて為替の売買シグナル(買い / 売り / 様子見)を表示する、Expo (React Native) 製のモバイル/Webアプリです。

## 主な機能

- GMOコインが取り扱う10通貨ペア(対円7ペア + クロス3ペア)を「対円」「クロス」でグループ表示するウォッチリスト
- **エントリー判定**: 「結局いま入っていいのか」を ○ / △ / × の1行で表示。ウォッチリストには各ペアに「条件クリア / サンプル不足 / 見送り」のラベルと、条件を満たすペアの件数を出します(後述)
- **エントリー時刻カウントダウン**: 15分足が確定する 00 / 15 / 30 / 45 分までの残り時間を秒単位で表示。残り1分を切ると色が変わり、エントリー準備の合図になります
- **統計にもとづく予測**(詳細画面):
  - **次の15分の想定レンジ**: 直近の15分足リターンの標準偏差から、約68%(±1σ)/約95%(±2σ)で収まる価格帯を算出
  - **現在シグナルの過去成績**: 表示期間内で同じシグナルが出た全ての足について、次の15分足がシグナル方向へ動いたかを集計した勝率・的中数・平均変動率。50%を境に色分けし、サンプルが少ない場合は警告を表示
  - 買い/売り両シグナルの勝率とサンプル数の比較
- **リアルタイム更新**: 現在値(BID/ASK/スプレッド)を**3秒ごと**に更新し、形成中の足としてチャートにも反映します
- **足の確定に合わせた自動更新**: 00 / 15 / 30 / 45 分の8秒後にローソク足を再取得します(シグナル計算には確定した足のみを使うため、判定が数秒ごとに揺れることはありません)
- **判定方針の切り替え**(自動 / 順張り / 逆張り)。選択は端末に保存され、切り替えてもAPIは再取得しません
- 各ペアの詳細画面で、15分足の価格チャート(1日 / 3日 / 5日分)とシグナル根拠を表示
- SMA(短期5本・長期20本)のクロス、RSI(14)、MACDヒストグラムを組み合わせたルールベースの売買シグナル
- Pull to refresh でウォッチリストを再取得
- Expo Web出力に対応し、スマホのブラウザからインストール不要で開けるモバイルWeb版あり

### エントリー判定の3条件

勝率は「次の足が予想方向へ動いたか」しか数えないため、**勝率が損益分岐を超えていても収支がマイナスになる**組み合わせが実際に出ます(当たった時の値幅より、外れた時の値幅が大きい場合)。これを勝率だけで見分けるのは無理なので、次の3条件をすべて満たした時だけ「条件クリア」としています。

| 条件 | 基準 | 理由 |
|---|---|---|
| 勝率 | **40%以上** | リスクリワード 1:1.5 での損益分岐 = 1 ÷ (1 + 1.5) |
| 1回あたりの期待値(コスト差引後) | **プラス** | 平均変動率 − スプレッド。方向が当たっても値幅で負ける組み合わせを弾く |
| サンプル数 | **30件以上** | これ未満は偶然と区別できない |

判定は3段階です。

| 表示 | 意味 |
|---|---|
| ○ **エントリー条件クリア** | 3条件すべて達成 |
| △ **条件は満たすがサンプル不足** | 勝率・期待値は達成、サンプルが30件未満 |
| × **エントリーしない** | 勝率または期待値が条件を満たしていない、あるいはシグナルなし |

期待値の判定には、現在値の bid/ask から求めた**往復スプレッド**を差し引いています(例: CHF/JPY で 196.32・スプレッド2銭なら約 0.010%)。現在値が取れていない場合はスプレッドを 0% として扱い、その旨を画面に表示します。

現在のシグナルが条件を満たさず、**反対方向なら満たす**場合は「このペアは『買い』なら3条件を満たします」と案内します。そのペアを切り捨てるのではなく、シグナルが切り替わるのを待つ判断ができるようにするためです。

判定はウォッチリストと詳細画面で同じ期間(既定3日)・同じ関数(`src/utils/verdict.ts` の `evaluateEntry`)を使うため、一覧と詳細で結論が食い違うことはありません。

### 判定方針(順張り / 逆張り / 自動)

RSI は「買われ過ぎ(70超)なら反転」という**逆張り**の指標として使われる一方、強いトレンド相場では「勢いが強い」ことを示す**順張り**のサインでもあります。同じ数値が正反対の意味を持つため、方針を選べるようにしています。

| 方針 | RSI > 70 の解釈 | 向いている相場 |
|---|---|---|
| 逆張り | 買われ過ぎ → 売り方向(−1) | 揉み合い |
| 順張り | 勢いが強い → 買い方向(+1) | 強いトレンド |
| 自動 | 効率比で判定して上記を切り替え | 全般 |

RSI が 30〜70 の範囲では順張りと逆張りの判定は完全に一致し、方針の違いは極端な水準でのみ現れます。

**自動**では Kaufman の効率比(Efficiency Ratio: 期間の正味の値動き ÷ 各足の値動きの合計、0〜1)を使い、`0.35` 以上をトレンド相場と判定して順張りに、それ未満を揉み合い相場と判定して逆張りに切り替えます。判定結果と効率比の実測値は画面上に表示されます。

逆張り単独では、一方向に伸びる強いトレンドで SMA の +1 と RSI の −1 が相殺してシグナルが出なくなる問題がありました(検証用のトレンド系列で発火 0 件)。順張り / 自動ではこれが解消されます(同じ系列で 99 件 / 98 件)。

どの方針が有効かは通貨ペアや時間帯で変わるため、方針を切り替えて**勝率の比較**ができるようになっています。統計は選択中の方針で再集計されます。

### 統計値の算出方法について

勝率は、画面表示中のシグナルと**まったく同じ判定ロジック**(`src/utils/signal.ts` の `scoreAt`)を過去の各足に適用して集計しています。表示と検証でロジックが食い違わないよう、両者は同じ関数を共有しています。

ただしこれは表示期間の過去データを集計した**過去成績**であり、将来の成績を保証するものではありません。想定レンジも価格がランダムに動くと仮定した統計的な目安で、方向性を予測するものではありません。

※ 本アプリは証券会社の口座・取引システムとは連携していない、独立したシグナル参考ツールです。発注機能はありません。

## データソース

**[GMOコイン「外国為替FX」の Public API](https://api.coin.z.com/fxdocs/) を使用しています（既定）。認証が不要なため、APIキーもトークンも設定不要で動作します。**

- 認証なし = **漏洩する秘密情報が存在しない**
- 口座開設も不要（Public APIのため）
- 15分足のローソク足と現在値の両方に対応
- 対応通貨ペアは10ペア（USD/JPY, EUR/JPY, GBP/JPY, AUD/JPY, NZD/JPY, CAD/JPY, CHF/JPY, EUR/USD, GBP/USD, AUD/USD）

ローソク足は日付単位で取得する仕様のため、必要な本数が揃った時点で取得を打ち切っています（10ペアで約20〜40リクエスト、同時実行は4本まで）。現在値は `ticker` が全銘柄を1リクエストで返すため、監視数によらず1回です。

現在値は3秒ごとに更新します(`ticker` は全銘柄を1リクエストで返すため、毎分20回で収まります)。

### CORSについて(重要)

**GMOのAPIはブラウザからの直接アクセスを許可していません(実機で確認済み)。** そのため次の2段構えにしています。

1. **中継サーバ経由(現在の構成)**: `gmo-proxy/` を Cloudflare Workers にデプロイ済み。ブラウザから中継サーバ経由でGMOを叩けるため、**3秒ごとのリアルタイム更新**になります
   - 稼働中: `https://hayabusa-fx-gmo-proxy.kei-047.workers.dev`
   - `.env` の `EXPO_PUBLIC_GMO_PROXY_URL` で指定
2. **フォールバック**: 中継サーバに届かない場合、GitHub Actions が公開した静的JSON(`gh-pages` の `data/`)を同一オリジンで読みます。表示は「〇分前の値」と明示されます

**中継サーバを立てる**: `gmo-proxy/` に用意しています。**このWorkerは秘密情報を一切持ちません**(GMOのPublic APIは認証不要のため)。ブラウザから直接接続できない場合はアプリが画面上にその旨と対処方法を表示するので、次の手順で中継を挟んでください。

```bash
cd gmo-proxy
npx wrangler login
npx wrangler deploy
# 表示されたURLを .env に設定
# EXPO_PUBLIC_GMO_PROXY_URL=https://your-worker.workers.dev
```

<details>
<summary>Twelve Data構成（旧）について</summary>

[Twelve Data](https://twelvedata.com/)の為替15分足API(`/time_series`)を使用します。

無料プランの上限は **8クレジット/分・800クレジット/日** です。バッチリクエストは「シンボル数 = 消費クレジット数」となるため、23ペアを一度に投げると即座に429(レート制限)になります。これを踏まえて次の対策を入れています。

- **分割取得**: 6ペアずつ・約65秒間隔で順に取得し、届いたぶんから画面に表示(最初の6ペアはすぐ表示されます)
- **キャッシュの永続化**: 取得結果は10分間 `localStorage` に保存するため、**ページを再読み込みしてもAPIを叩き直しません**。これがないと、リロードのたびにクレジットを消費して429を誘発します
- **429からの自動復帰**: レート制限に当たっても待機して自動で再試行します(最大3回)。画面には待機中である旨を表示し、エラーにはしません

1回の全体更新でペア数ぶんのクレジットを消費します。予備の80クレジットを残す設計のため、ウォッチリストの自動更新は**1日あたり31回(連続約7.8時間ぶん)**まで動き、それを超えると自動更新のみ停止します(手動更新は引き続き可能)。詳細画面の自動更新は1回1クレジットなので、1日中開いていても96クレジットで収まります。

</details>

### 国内業者のAPI事情(調査結果)

| 業者 | 個人向けAPI | 備考 |
|---|---|---|
| **GMOコイン** | ✅ **認証不要のPublic API** | 本アプリの既定。口座不要 |
| OANDA証券 | △ 条件あり | GOLD会員 + NYサーバー残高25万円 + **プロコース**が必要。プロコースはスプレッドが倍(0.4銭→0.8銭)になる |
| デューカスコピー・ジャパン | ✅ FIX API / JForex API | Java中心 |
| 松井証券 | ❌ 事業者向けのみ | QUOREA FX等との接続用 |
| ライオンFX(ヒロセ通商) | ❌ なし | 自動売買はツール内「シグナル注文」のみ |

証券会社のAPIトークンは**発注権限を持つ**ため、静的ページのJSに埋め込むことはできません(公開ページのJSは誰でも読めます)。OANDA構成を使う場合はトークンをサーバー側に置くプロキシが必須です(`oanda-proxy/` に実装済み)。**GMOのPublic APIは認証自体が無いため、この問題が発生しません。**

## セットアップ

APIキーの設定は不要です。

```bash
npm install
npx expo start
```

Expo Go アプリ(iOS / Android)で表示された QR コードを読み取るか、iOS シミュレータ / Android エミュレータで起動してください。

## モバイルブラウザ版(Web版)

インストール不要で、スマホの Safari / Chrome から直接使えるWeb版も用意しています。

```bash
npx expo start --web
```

表示されたURLをスマホのブラウザで開いてください。スマホ幅に最適化されたレイアウトで、PCなど広い画面で開いた場合も中央にスマホ相当の幅で表示されます。

配信用に静的ファイルを書き出す場合は以下を実行し、`dist/` を任意のホスティングサービスにアップロードしてください。既定構成では**バンドルに秘密情報が含まれません**。

```bash
npx expo export --platform web
```
